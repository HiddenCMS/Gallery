# HiddenCMS Gallery

Module de galeries photo pour HiddenCMS.

## Fonctionnalités

- catégories de galeries ;
- sélection d'un dossier depuis la médiathèque ;
- prise en charge des images JPEG et PNG du dossier sélectionné ;
- contenu éditorial avant et après les images ;
- affichage en cascade responsive ;
- visionneuse accessible avec navigation au clavier.

## Installation

```bash
composer require hiddencms/gallery
```

Le module requiert HiddenCMS 0.7 ou supérieur. Après installation, synchronisez les addons et exécutez les migrations si les scripts Composer ne sont pas actifs.
