# Gallery 0.1.2

- Integration dans les blocs de contenu du module Pages.
- Sources : toutes les galeries ou une categorie.
- Affichage en cartes ou en liste verticale.
- Nombre de galeries visibles configurable entre 1 et 24.
- Seules les galeries publiees sont affichees.

Aucune migration SQL. Compatible avec HiddenCMS ^0.7.2.
